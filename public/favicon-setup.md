# Your favicon package

Generated by favicon.zip — https://favicon.zip

## Install (Plain HTML)

1. Copy the files to the root of your site (so they answer at `/favicon.ico` etc).
2. Paste this into your `<head>`:

```html
<link rel="icon" href="/favicon.ico" sizes="32x32">
<link rel="icon" href="/favicon-96x96.png" type="image/png" sizes="96x96">
<link rel="apple-touch-icon" href="/apple-touch-icon.png">
<link rel="manifest" href="/manifest.webmanifest">
```

## What's inside

| File | Purpose |
| --- | --- |
| `favicon.ico` | Served from `/favicon.ico` so crawlers and RSS readers find it without parsing your HTML. Contains 16, 32, 48px layers. |
| `apple-touch-icon.png` | 180×180 icon for iOS home screens. Opaque, because iOS paints transparent pixels black. |
| `favicon-96x96.png` | 96×96 PNG for Google Search results. |
| `icon-192.png` | Android / PWA home screen icon. |
| `icon-512.png` | PWA splash screen and install UI. |
| `icon-mask.png` | Maskable icon. Extra padding keeps your mark inside the safe zone when Android crops it into a circle or squircle. |
| `manifest.webmanifest` | Web app manifest wiring the PWA icons together. Edit `name` and `short_name`. |
| `favicon-setup.md` | This file. Reference only — safe to delete once installed. |

## Notes

- Keep `favicon.ico` at your site root — don't rename or nest it.
- The `sizes="32x32"` attribute on the ICO link works around a Chrome quirk where it prefers ICO over SVG.
- The manifest, the 192/512 icons, and `icon-mask.png` are only needed for PWA installs.
